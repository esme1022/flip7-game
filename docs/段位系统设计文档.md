# 段位系统设计文档

## 一、系统概述

本游戏平台包含三个游戏模式：**竞技模式**、**娱乐模式**、**血拼模式**。段位系统仅作用于竞技模式，覆盖该模式下的全部玩法（Flip7 经典、Uno 经典、大话牌），采用三个玩法**共享同一段位**的设计。

### 段位层级

| 阶段 | 称号 | 世界观含义 |
|:---:|------|----------|
| 1 | 兔洞来客 | 刚掉进地下世界的外来者，懵懂无知 |
| 2 | 暗巷常客 | 在地下名利场混熟了，是暗巷里的老面孔 |
| 3 | 茶会弄臣 | 在疯帽匠的牌桌上有了一席之地，灵活周旋 |
| 4 | 红桃暴君 | 用实力碾压牌局，名利场上令人畏惧 |
| 5 | 黑桃王座 | 登上最高花色的王座，地下世界的统治者 |
| 6 | 提线人 | 王座只是道具，真正的权力在幕后拉线 |

### 晋级规则

- 每个段位内设 **3颗星**
- 竞技模式获胜 = **+1星**，失败 = **-1星**
- 0星时失败不掉段（保底机制）
- 最高段位「提线人」采用积分制：赢+10，输-8，显示排名

### 各模式段位关系

| 模式 | 段位 | 经济体系 |
|------|------|---------|
| 竞技模式 | 共享段位（六阶） | 金币（赢了按比例加，输了不减） |
| 娱乐模式 | 无段位 | 金币（赢了加，输了不减） |
| 血拼模式 | 无段位 | 血量 + 紫晶（独立经济体系） |

## 二、为什么竞技模式共享段位

### 2.1 平台定位决定了答案

本平台是**社交聚会型桌游合集**，不是单一电竞游戏。玩家来到这里是为了"什么都能玩"，而不是专精某一个玩法。共享段位鼓励玩家广泛尝试不同玩法，保持平台各玩法的活跃度，避免出现"某个玩法无人问津"的冷门困境。

如果每个玩法独立段位，玩家会倾向于只打自己最擅长的那个游戏来冲段，这与平台"桌游合集"的核心定位相矛盾。

### 2.2 行业参考：Liar's Bar

Steam 热门桌游 **Liar's Bar** 同样采用多玩法共享段位的设计（Liar's Deck、Liar's Dice、Liar's Poker、Liar's Roulette 共享一个段位）。其段位的本质是"你在这家酒馆里的江湖地位"，而不是"你打某个游戏有多强"。这使得共享段位在玩家认知中毫无违和感——你不是某个游戏的高手，你是这家酒馆里的狠角色。

本平台沿用了这一设计哲学，并通过世界观包装进一步强化了合理性。

### 2.3 避免信息过载

平台已有四种货币/资源体系（金币、钻石、血量、紫晶）。如果再为三个竞技玩法各设独立段位，大厅的信息密度会过高，增加新玩家的认知负担。一个统一的竞技段位简洁有力，放在头像旁边就是最直观的身份象征。

### 2.4 段位含金量更高

共享段位意味着"这个人什么桌游都能打"，比单一玩法段位更有社交价值。在聚会型桌游的语境下，"什么都会玩的全能型选手"比"只会打某一个游戏"更值得尊敬。这与现实中"桌游高手"的社交认知完全一致。

## 三、为什么这样命名段位

### 3.1 核心问题：命名框架决定玩家认知

传统段位命名（青铜、白银、黄金、钻石）强调的是**竞技水平等级**。这种框架下，玩家会自然地将段位与特定游戏的胜负挂钩，一旦在某个不擅长的玩法中失败导致掉段，就会产生"不合理"的负面感受——"我Flip7明明很强，为什么被Uno拖后腿？"

要让共享段位被玩家自然接受，段位名称必须描述的是**"你在这个世界里是谁"**，而不是**"你打某个游戏有多强"**。

### 3.2 世界观驱动的命名策略

本平台的世界观是**暗黑童话风格的地下名利场**：爱丽丝风格的小动物体系，大家在一个 underground 的名利场里玩游戏，像是在进行黑暗交易。

基于这个世界观，段位称号代表的是玩家在这个地下世界中的**身份地位**，而非竞技水平。这从根本上消除了"为什么 Uno 影响我段位"的认知冲突——因为你的段位不是衡量你打某个游戏的水平，而是衡量你在这个地下名利场里的名望和地位。在名利场里闯荡，当然什么牌局都要接得住。

### 3.3 命名的叙事线设计

六个段位构成一条完整的暗黑童话升迁故事线：

```
外来者 → 熟客 → 弄臣 → 暴君 → 王座 → 提线人
```

**第一阶段：兔洞来客（入门）**
- 爱丽丝追着兔子掉进兔洞——玩家刚进入这个地下世界
- "来客"强调外来者身份，暗示"你还不属于这里"
- 设计意图：给新玩家一个明确的起点感，同时勾起"我要变成这里的人"的进阶欲望

**第二阶段：暗巷常客（融入）**
- 从"来客"到"常客"，身份发生了质变——你不再是外人
- "暗巷"点明地下世界的氛围，"常客"是一个社交身份而非竞技称号
- 设计意图：让玩家感受到"我在这个世界里站稳脚跟了"

**第三阶段：茶会弄臣（崭露头角）**
- 引用爱丽丝的"疯帽匠茶会"——你在核心圈子里有了座位
- "弄臣"是一个有趣的身份：聪明、灵活、善于周旋，但还不是真正的权力者
- 设计意图：中间段位需要有"正在上升"的动态感，弄臣恰好是"有能力但还在积累"的隐喻

**第四阶段：红桃暴君（称霸）**
- "红桃"直接引用扑克牌花色和爱丽丝中的红心女王
- "暴君"比"王"更有攻击性——你是靠实力碾压上来的
- 设计意图：这是一个让人敬畏的段位，看到对手是"红桃暴君"会下意识紧张

**第五阶段：黑桃王座（登顶）**
- 黑桃在多数扑克体系中是最高花色，高于红桃
- "王座"而非"国王"——强调的是位置本身的权力，而非个人
- 设计意图："红桃暴君"到"黑桃王座"是从"人"到"位"的跃迁，你已经不只是一个强者，你坐在了最高的位置上

**第六阶段：提线人（超越）**
- 所有人都在牌桌上博弈，只有提线人在幕后操控一切
- 这个称号跳出了"牌桌上的角色"框架，暗示了一种更高维度的存在
- 设计意图：最高段位必须有"超越感"。暴君在桌上杀人，王座统治桌面，而提线人——他不需要坐在桌前，因为线在他手里

### 3.4 为什么不用传统命名

| 对比维度 | 传统命名（青铜/白银/黄金） | 本方案（兔洞来客→提线人） |
|---------|------------------------|------------------------|
| 玩家认知模型 | "我打这个游戏的水平" | "我在这个世界里的地位" |
| 共享段位的接受度 | 低——"为什么 Uno 影响我段位？" | 高——"在名利场里什么都要接得住" |
| 叙事感 | 无——纯等级标签 | 强——完整的暗黑童话升迁线 |
| 与世界观的契合度 | 零——通用化称号 | 深度绑定——每个称号都是世界观的一部分 |
| 晋级仪式感 | 低——只是换了个颜色/金属 | 高——身份质变，配合晋级文案有代入感 |
| 视觉徽章设计空间 | 小——金属/宝石色调 | 大——兔子、暗巷、扑克牌、王冠、提线木偶 |

## 四、这套设计的核心好处

### 4.1 消除共享段位的认知摩擦

通过世界观包装，将"段位=游戏水平"的固有认知替换为"段位=名利场地位"。玩家不会质疑"为什么不同玩法影响同一个段位"，因为在暗巷名利场里，你的地位本来就取决于你在所有牌桌上的综合表现。

### 4.2 驱动玩家尝试多种玩法

当段位代表的是"你在这个世界里有多厉害"时，玩家自然会想在所有玩法中证明自己，而不是只死磕一个最擅长的。这对平台生态至关重要——保证每个竞技玩法都有足够的活跃用户。

### 4.3 强化平台世界观和品牌辨识度

每一个段位称号都是平台世界观的延伸。当玩家在社交媒体上说"我是红桃暴君"或"我终于到提线人了"，这些带有强烈辨识度的称号本身就是平台的免费传播素材。相比"我是钻石段位"这种通用表述，暗黑童话风格的称号更具记忆点和传播力。

### 4.4 创造晋级仪式感和情感驱动

每个段位都伴随一段叙事性的晋级文案，例如：

> *"疯帽匠为你斟上一杯红茶，低声说：'往上坐吧。'——恭喜晋升【茶会弄臣】"*

> *"暗巷里的低语中，你的名字开始被更多人提起——恭喜晋升【红桃暴君】"*

> *"王座上的人站起来了。不是让位，是因为他不再需要坐着——恭喜晋升【提线人】"*

这种叙事驱动的晋级体验远比"恭喜升入黄金段位"更能激发玩家的成就感和分享欲。

### 4.5 简洁的信息架构

三个模式、三套规则，但只需要展示一个段位。玩家打开个人资料，看到一个段位徽章 + 各玩法胜率，信息层次清晰：

```
🃏 红桃暴君 ★★☆
├── Flip7 经典   胜率 68% (42场)
├── Uno 经典     胜率 55% (31场)
└── 骗子酒馆      胜率 72% (18场)
```

段位代表综合实力，胜率补充细节，两者不冲突。

## 五、娱乐模式和血拼模式为什么不设段位

### 娱乐模式

娱乐模式（文字麻将、大话骰）的核心体验是**轻松有趣**，加入段位会引入不必要的竞争压力，破坏"休闲娱乐"的定位。这些玩法的赢家通过金币奖励获得正反馈，足以维持参与动力。

### 血拼模式

血拼模式已有完整的**血量 + 紫晶**经济体系作为进阶驱动力。血量消耗和紫晶收益本身就构成了"高风险高回报"的激励循环，再叠加段位系统会导致激励过载，且血拼模式的"赌命"调性与段位的"稳定攀升"逻辑存在冲突。
